requirements:
1- video
2- batch file
3- which program supports viewing RTSP video. (download link: "https://www.videolan.org/vlc/")
4- mediamtx server (download link: https://github.com/bluenviron/mediamtx/releases/download/v1.13.1/mediamtx_v1.13.1_windows_amd64.zip)


---------------------------------------------------------------------------------------------------------------------------------------

operating steps:

1- Open the batch file ("1-Stream_RTSP.bat") in edit mode and modify VIDEO_PATH, FFMPEG_PATH, MEDIA_MTX_PATH, and VLC_PATH as it is on your device

2- open "1-Stream_RTSP.bat" --> This starts RTSP streaming from the video "sample.mp4"

3- watch stream:
	- open VLC media player
	- Media --> Open Network Stream
	- place the live stream link as specified in the batch file(rtsp://127.0.0.1:8554/mystream)
	- Click on "play"
